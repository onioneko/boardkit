    projection

    • projection<T = unknown>(
          docId: string,
          projectorId: string,
          opts: { options?: Readonly<Record<string, unknown>>; source?: Source },
      ): Promise<ProjectionResult<T>>

      Project one document through a projector. Fail-soft: a throwing projector degrades to its Projector.degrade output (the raw source text when it declares none) plus an E_PROJECTOR_ERROR diagnostic, and a projection middleware that throws a WriteRejection degrades the same way with that rejection's diagnostics attached — neither ever throws out of this method. A block whose hook throws degrades alone: the built-in projectors render it as its verbatim source and report E_BLOCK_HOOK_ERROR.

      Type Parameters

      • T = unknown

        The projector's output type, asserted by the caller: the engine passes the projector's return value through untouched and does not check it. Defaults to unknown, which forces narrowing at the call site.

      Parameters

      • docId: string

        The document to project.

      • projectorId: string

        The projector to run: "text" out of the box, or any id registered through EngineOptions.projectors or Engine.registerProjector. An unregistered id is not an error — it comes back ok: false with an E_UNKNOWN_PROJECTOR diagnostic.

      • opts: { options?: Readonly<Record<string, unknown>>; source?: Source }

        The Source port used to resolve {{source:…}} refs (optional — absent resolves no refs), plus any projector options.

      Returns Promise<ProjectionResult<T>>

      The projection output, diagnostics, and reachable-doc versions.

      Example

      const r = await engine.projection<string>("fin", "text", { source });
      r.output.length;
      console.log(r.versions);
