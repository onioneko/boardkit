    • onUnresolvedSource?(
          ref: SourceRef,
          state: { stale: boolean; value?: string },
          raw: string,
          ctx: ProjectionWalkContext,
          span?: SourceSpan,
      ): T

      A {{source:…}} span whose value is stale or did not resolve at all. Optional: when omitted, such a span stays verbatim prose (part of the surrounding onProse run), exactly as before this handler existed.

      Supply it when the projector needs a keyed piece for every reference — a live view that fills a value in later, for one — and must tell a stale reference from prose that happens to read {{source:x}}. It changes only what this span becomes: ProjectionWalkContext.hookValues still omits stale and missing values, so block hooks keep rendering their own fallback and never see a placeholder.

      Parameters

      • ref: SourceRef

        The reference as parsed (source id and params, param-bearing refs included).

      • state: { stale: boolean; value?: string }

        { stale: true, value } when the resolution degraded, where value is the source's degradation marker (not real data); { stale: false } with no value when the projection's values hold no entry for this ref.

      • raw: string

        The reference's verbatim source, {{ to }}.

      • ctx: ProjectionWalkContext

        The node being walked.

      • Optionalspan: SourceSpan

        The reference's span in ctx.node.src, {{ to }}.

      Returns T

      What to emit in the reference's place; raw reproduces the output a walk without this handler gives.

      Example

      onUnresolvedSource: (ref, state) =>
        h("span", { "data-source": ref.source, "data-stale": String(state.stale) }),
