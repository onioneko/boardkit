    Optional ReadonlycomplexityLimits

    complexityLimits?: false | ComplexityLimits

    Documents over a markdown complexity limit are not parsed, with the same outcome as an oversized one and an E_DOCUMENT_TOO_COMPLEX diagnostic. Absent takes DEFAULT_COMPLEXITY_LIMITS; false turns the check off. An invalid value is a programming error: resolveIncludes rejects with a TypeError.

    Optional ReadonlymaxDocumentBytes

    maxDocumentBytes?: number

    Documents over this many UTF-8 bytes are not parsed: the board yields an empty result and an include of one is left unexpanded, each with an E_DOCUMENT_TOO_LARGE diagnostic. Defaults to DEFAULT_MAX_DOCUMENT_BYTES (256 KiB).

    Optional Readonlyparse

    parse?: (docId: DocId, src: string) => ParsedDoc

    Parse one reachable document. Defaults to parseDoc(src, options); the engine passes its content-keyed parse cache here, so a document is parsed once per content rather than once per resolution pass.
