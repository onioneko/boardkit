    Function sanitizePanelHast

    • sanitizePanelHast(tree: Root): Root

      The html projector's whole sanitize pass, for a projector that builds hast itself (with projectHast or otherwise) and wants exactly the html projector's policy:

      1. data-doc/data-section are removed from every element that is not an includeWrapper, so hook output cannot fake include provenance;
      2. href/src schemes are lowercased, so HTTPS: and MAILTO: URLs pass the case-sensitive scheme check;
      3. the tree is sanitized with panelSchema;
      4. every <label> is pruned to its className (pruneLabelAttributes);
      5. GFM footnote links get the user-content- prefix their targets' ids got.

      projectHtml runs this function and nothing else, so the two never differ.

      Parameters

      • tree: Root

        The unsanitized tree. It may be mutated; use the return value.

      Returns Root

      A new, sanitized tree.

      Example

      const safe = sanitizePanelHast(await projectHast(walk, handlers));
