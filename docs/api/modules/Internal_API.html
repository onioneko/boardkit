    Module Internal API

    @onioneko/boardkit-core/internal — mechanism internals.

    These symbols implement the engine's parse → link → validate → resolve → merge → project → diff → emit → write pipeline. They are exported for library authors and advanced hosts who compose the pipeline stages themselves; they carry no stability guarantee and may change between minor releases. Prefer the consumer surface (@onioneko/boardkit-core) unless you need a specific mechanism.
