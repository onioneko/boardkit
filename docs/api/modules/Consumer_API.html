    Module Consumer API

    @onioneko/boardkit-core — the public consumer API.

    This is the stable surface for hosts and ecosystem authors: engine assembly, the write and intent domains, block and model types, ports and their default adapters, watch wiring, projection options, merged-tree data, middleware, and events. Mechanism internals (parse/link/resolve/validate/diff/project/write pipeline machinery) live under @onioneko/boardkit-core/internal and carry no stability guarantee.
